usage: asb store NAME --hosts H[,H] [--field F] [--item I] [--var V]   < value

Create a new credential. The value is read from stdin (or a hidden prompt on a
terminal), never from an argument. --hosts is required: where it may be used.
example: printf '%s' "$TOKEN" | asb store myapi --hosts api.example.com
SSH key: asb store NAME --ssh < unencrypted_private_key   (no --hosts; use with asb ssh-agent)
